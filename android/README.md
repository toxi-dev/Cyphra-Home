# Cyphra Home for Android

An everyday Gecko browser with Brave Search, real local ad blocking, bookmarks, private tabs, downloads, appearance controls and signed updates. Home has a single Personal profile and follows system DNS unless you choose another resolver. It has no cybersecurity workspace or research tools.

The application ID is `org.cyphra.browser.home`; signed releases come only from `toxi-dev/Cyphra-Home`. Home data and updates are separate from the other editions. No telemetry SDK is included.

See the repository README for privacy limits, source and build instructions.
